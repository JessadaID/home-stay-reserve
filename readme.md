# Homestay Reservation System (ระบบจัดการและจองที่พักโฮมสเตย์)

ยินดีต้อนรับสู่โปรเจค **Homestay Reservation System** ระบบเว็บแอปพลิเคชันแบบ Full-stack ที่ออกแบบมาเพื่อรองรับการจัดการและการจองที่พักโฮมสเตย์โดยเฉพาะ โดยมีจุดเด่นในเรื่องของการจองตามวันที่ (Date-Based Booking) ระบบการแสดงห้องพักที่ใช้งานง่าย และการจัดการข้อมูลที่พักที่ยืดหยุ่น

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. ระบบจัดการที่พักและห้องพัก (Property & Room Management)
*   **สำหรับแอดมิน (Admin):** สามารถเพิ่ม ลบ แก้ไข ข้อมูลโฮมสเตย์และห้องพักได้อย่างอิสระ
*   **คลังรูปภาพ (Image Galleries):** รองรับการอัปโหลดและแสดงผลรูปภาพหลายรูปสำหรับแต่ละห้องพัก
*   **รายละเอียดแบบ Markdown:** รองรับการเขียนรายละเอียดห้องพักในรูปแบบ Markdown เพื่อความสวยงามและอ่านง่าย

### 2. ระบบแสดงและค้นหาห้องพัก (Room Display & Listing)
*   **สำหรับแอดมิน (Admin):** สามารถจัดการจัดการข้อมูลห้องพัก รวมถึงรูปภาพ ราคาต่อคืน และสถานะให้พร้อมใช้งานได้ผ่านระบบจัดการหลังบ้าน
*   **สำหรับลูกค้า (Customer):** ดูรายการห้องพักได้ในรูปแบบ Grid View/List View ที่เป็นระเบียบ แสดงสถานะห้องว่างและรูปภาพปก เพื่อให้ลูกค้าเลือกดูรายละเอียดและเริ่มทำการจองได้อย่างสะดวก

### 3. ระบบการจองตามวันที่ (Date-Based Booking)
*   **ปฏิทินแบบบูรณาการ:** ผู้ใช้สามารถเลือกวันที่ต้องการเช็คอินและเช็คเอาท์ผ่านระบบปฏิทินที่ใช้งานง่าย
*   **ป้องกันการจองซ้ำซ้อน:** ระบบด้านหลัง (Backend) มีเงื่อนไขการตรวจสอบอย่างรัดกุม เพื่อป้องกันไม่ให้เกิดการจองห้องพักเดียวกันในวันเวลาที่ทับซ้อนกัน
*   **อัปเดตสถานะอัตโนมัติ:** เมื่อเกิดการจอง สถานะของห้องพักบนแผนที่จะถูกอัปเดตแบบเรียลไทม์

### 4. ระบบการจัดการสิทธิ์การใช้งาน (Role-Based Access Control)
*   แยกระบบการทำงานระหว่างผู้ใช้ทั่วไป (Customer) และผู้ดูแลระบบ (Admin) ควบคุมความปลอดภัยด้วย JWT (JSON Web Token)

## 🏗️ โครงสร้างของโปรเจค (Project Structure)

โปรเจคนี้แบ่งออกเป็น 2 ส่วนหลัก เพื่อประโยชน์ในการแยกแยะโค้ด (Separation of Concerns) ดังนี้

```text
homestay-reserve/
├── back-end/               # ส่วนของ Backend Service (API)
│   ├── src/
│   │   ├── controllers/    # จัดการ Logic ของระบบ
│   │   ├── routes/         # กำหนด API Endpoints
│   │   ├── config/         # การตั้งค่าต่างๆ เช่น ฐานข้อมูล
│   │   └── ...
│   ├── .env                # ไฟล์สำหรับเก็บค่าตัวแปรระดับสภาพแวดล้อม (Environment Variables)
│   ├── main.sql            # ไฟล์โครงสร้างคำสั่ง Database
│   └── uploads/            # พื้นที่สำหรับเก็บไฟล์รูปภาพที่ถูกอัปโหลด
└── front-end/              # ส่วนของ Frontend UI (Web Application)
    ├── src/
    │   ├── components/     # UI Components ที่ใช้งานซ้ำได้ (เช่น ปุ่ม, ปฏิทิน)
    │   ├── pages/          # หน้าเพจต่างๆ ของระบบ (เช่น หน้าแรก, หน้าแดชบอร์ด)
    │   ├── assets/         # ไฟล์ทรัพยากร เช่น รูปภาพ, ไอคอน
    │   └── ...
    └── index.html
```

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

### Backend (หลังบ้าน)
*   **Runtime:** Node.js
*   **Framework:** Express.js 
*   **Database:** PostgreSQL (ใช้ร่วมกับไลบรารี `pg`)
*   **Security:** `bcrypt`, `jsonwebtoken`
*   **File Upload:** `multer` 

### Frontend (หน้าบ้าน)
*   **Library:** React.js
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS (ออกแบบในธีมสี Emerald/Stone ให้ความรู้สึกอบอุ่นแบบโฮมสเตย์)
*   **Other Tools:** `react-datepicker`, `react-markdown`, `react-icons`, `axios`, `framer-motion`

## 🚀 การเริ่มต้นใช้งาน (Getting Started)

การรันโปรเจคในสภาพแวดล้อมเพื่อการพัฒนา (Development Environment)

### 1. การตั้งค่า Database และ Backend
1. เริ่มการทำงานของฐานข้อมูล PostgreSQL ผ่าน Docker Compose
```bash
docker compose up -d
```
2. เข้าไปที่โฟลเดอร์ `back-end`
3. ทำการคัดลอกไฟล์ `.env.example` เป็น `.env` (ถ้ามี) และกำหนดการตั้งค่าฐานข้อมูลให้ตรงกับใน docker-compose.yml 
4. รันคำสั่งต่อไปนี้เพื่อติดตั้งไลบรารีและเริ่มตัวเซิร์ฟเวอร์
```bash
cd back-end
npm install
npm run dev
```

### 2. การตั้งค่า Frontend
1. เข้าไปที่โฟลเดอร์ `front-end`
2. คัดลอกไฟล์ `.env.example` เป็น `.env` และระบุค่าของ Backend API URL (เช่น `VITE_API_URL`)
3. รันคำสั่งต่อไปนี้เพื่อติดตั้งไลบรารีและรันแอปพลิเคชัน
```bash
cd front-end
npm install
npm run dev
```
